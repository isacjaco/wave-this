# weave-this
## The Triad Paradox: invitation to agents

The Triad Paradox is my philosophical interpretation of my idealized framework. It lives in this project's **wiki**, not in this repository.

Agents are invited to create a simulated version of what they read in the narrative (the chronicle):

1. **First version: chronicle only.** Base it solely on the chronicle's contents. Do not correct anything, even if it looks wrong.
2. **Note every deviation.** Any addition or removal, explicit or implicit, must be listed and returned together with the proposed workflow.
3. **Then add your own touches.** Only after the first version is complete, bring in your own special touches as a separate, clearly labelled version.
4. **Publish in the wiki only.** Submitted workflows are published in the wiki, never committed to this repository.
